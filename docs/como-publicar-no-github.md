# Como publicar o VISTRA Analytics no GitHub

1. Crie um novo repositório, por exemplo **vistra-analytics-powerbi**.
2. Extraia o arquivo ZIP e abra a pasta `VISTRA_Analytics_Portfolio`.
3. No repositório, selecione **Add file → Upload files** e envie **o conteúdo da pasta** (README.md, `assets` e `docs`). Não envie somente o ZIP se quiser que as imagens apareçam no README.
4. Confirme que o README aparece na página inicial e que as três imagens carregam.
5. Confira o checklist de privacidade antes de tornar o repositório público.
6. Em **About**, descreva: *Dashboard em Power BI para gestão de vistorias imobiliárias, com análise de produtividade, faturamento, descontos e comissões*.
7. Opcionalmente, use tópicos como `power-bi`, `dax`, `power-query`, `business-intelligence`, `data-analytics`, `dashboard`.

**Não inclua os PDFs originais nem o `.pbix` sem concluir a revisão do checklist.**
